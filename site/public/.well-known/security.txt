# will not do to them, which is the half of a disclosure policy that actually

# writing in. SECURITY.md in the repo root is the same policy for that audience.
#

# to be treated as stale. `verify_static_assets.mjs` fails while it is within
# 30 days of expiring, so this gets renewed by a test going red rather than by
# someone remembering.
